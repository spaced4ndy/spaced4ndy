### Backend and distributed-systems engineer · Haskell

Founding engineer at [SimpleX Chat](https://github.com/simplex-chat/simplex-chat) since 2020: an open-source, private messaging network with no user identifiers and 1M+ Google Play installs. I built large parts of its Haskell client core and the chat relays behind channels, design much of the chat protocol and wrote 30+ design RFCs. Since 2023 I've also authored over a third of the iOS app's code changes, and over half in 2026.

#### Selected work

- **Chat relays for SimpleX Channels** (2025–26): subscribers connect only to relays, so owners send each post once per relay, not per subscriber: [RFC and threat model](https://github.com/simplex-chat/simplex-chat/blob/stable/docs/rfcs/2025-10-20-chat-relays.md), [Haskell core](https://github.com/simplex-chat/simplex-chat/pull/6383), [iOS](https://github.com/simplex-chat/simplex-chat/pull/6634), [Android/desktop](https://github.com/simplex-chat/simplex-chat/pull/6670)
- **Group send cost** (2025): temporary storage to send one message to 1,000 members cut from ~20 MB to ~200 kB by deferring body encryption to delivery and storing the shared body once: [encrypt on delivery](https://github.com/simplex-chat/simplexmq/pull/1446), [shared body stored once](https://github.com/simplex-chat/simplexmq/pull/1453)
- **Restart-safe group delivery** (2025): delivery moved from the receive loop to persistent jobs that resume after restarts ([delivery jobs](https://github.com/simplex-chat/simplex-chat/pull/6178)); per-pair member records replaced by one compact vector per member, migrated on users' devices ([RFC](https://github.com/simplex-chat/simplex-chat/blob/stable/docs/rfcs/2025-11-24-member-relations-vector.md), [vector operations](https://github.com/simplex-chat/simplex-chat/pull/6459))
- **PostgreSQL alongside SQLite** behind one store interface, for server-side clients such as chat relays: [client library](https://github.com/simplex-chat/simplexmq/pull/1421), [chat core](https://github.com/simplex-chat/simplex-chat/pull/5403)
- **Transport security**: the messaging protocol's move to TLS, with a server identity check against the certificate fingerprint in each server's address: [transport over TLS, old RSA/AES handshake removed](https://github.com/simplex-chat/simplexmq/pull/229), [certificate validation](https://github.com/simplex-chat/simplexmq/pull/234), [offline and online certificates](https://github.com/simplex-chat/simplexmq/pull/238)
- **End-to-end encryption**: post-quantum encryption integrated into the chat protocol ([RFC](https://github.com/simplex-chat/simplex-chat/blob/stable/docs/rfcs/2024-02-28-pq-integration.md), [core](https://github.com/simplex-chat/simplex-chat/pull/3859)); recovery for broken double-ratchet sessions ([client library](https://github.com/simplex-chat/simplexmq/pull/774), [chat core](https://github.com/simplex-chat/simplex-chat/pull/2653), [iOS](https://github.com/simplex-chat/simplex-chat/pull/2663), [Android](https://github.com/simplex-chat/simplex-chat/pull/2666))
- **XFTP file transfer**: the client agent ([file descriptions](https://github.com/simplex-chat/simplexmq/pull/633), [receiving](https://github.com/simplex-chat/simplexmq/pull/637), [recoverable sending](https://github.com/simplex-chat/simplexmq/pull/707)) and most of its integration into the chat core and apps, 35+ PRs ([receiving files](https://github.com/simplex-chat/simplex-chat/pull/1997), [enabled by default](https://github.com/simplex-chat/simplex-chat/pull/2198))
- **AI-assisted development** (2026): CI workflows in which Claude Code can test the iOS, Android and desktop apps (400+ test cases on each for the v7.1 release): [iOS](https://github.com/simplex-chat/simplex-chat/pull/7737), [Android](https://github.com/simplex-chat/simplex-chat/pull/7786), [desktop](https://github.com/simplex-chat/simplex-chat/pull/7736)

**Other open source:** TLS 1.3 support in the Haskell tls library's Finished-message API ([hs-tls#445](https://github.com/haskell-tls/hs-tls/pull/445), co-authored) · Apache Spark Structured Streaming, released in Spark 2.4 ([ordered epoch commits, SPARK-23503](https://github.com/apache/spark/pull/20936), [EpochCoordinator tests, SPARK-23747](https://github.com/apache/spark/pull/20983))
